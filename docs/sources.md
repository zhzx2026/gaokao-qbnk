# 来源分级与采信规则（不要野题）

本库的第一原则是**可溯源**：一条题目如果找不到公开的、能点开的出处，就不允许进入正式题库。
所有来源集中登记在 [`sources/registry.json`](../sources/registry.json)，每条题目通过 `source.source_id` 指向登记表。

## 1. 来源分级（Tier）

| 等级 | 含义 | 典型来源 | 正文入库 | 默认 verification.status |
| --- | --- | --- | --- | --- |
| **T1** | 命题机构官方发布 | 教育部教育考试院（《中国考试》）、各省教育考试院/招生考试机构官网 | 允许 | `verified` |
| **T2** | 官方授权或权威媒体首发/全文转载 | 中国教育在线（考试院授权发布）、新华网、人民网、京报网 | 允许 | `single_source`（补 T1 后升 `verified`） |
| **T3** | 大型教育媒体/教辅机构整理稿、公开许可的开放数据集 | 大学生必备网、本地宝、新浪教育、GitHub 开放数据集（deekur/gaokaomath 等） | 允许 | `single_source` |
| **T4** | 社区/UGC/二次转载/文库/网盘/公众号/AI 生成 | 百度百科、华禹教育网、各类转载号、Reciter 社区题库 | **不允许**（仅作线索） | — |

- T4 只能作为**线索**登记在 `data/quarantine/`（隔离区），经 T1–T3 交叉验证一致后才可提升为 T3 并转入正式库。
- 商业题库（学科网、菁优网等）标记为 `access: login-required` + `full_text_policy: index_only`：可人工摘录**已获授权**的内容并注明来源，但**不提供自动抓取适配器**。

## 2. 什么算"野题"（一律拒收）

出现以下任一情况，题目不得入库（`verification.status = rejected`，放入 `data/quarantine/`）：

1. **无 URL**：只有"网传""某名校内部卷""朋友发的"等描述，给不出可访问的公开链接；
2. **来源不可核验**：网盘/文库/付费墙背后、需要登录才能看到正文、链接已失效且无存档；
3. **AI 生成或二次洗稿**：由大模型凭印象"复原"的高考题、把真题改几个数字变成的"新题"；
4. **答案缺失或自相矛盾且无法核对**：尤其是客观题，答案必须来自官方答案/评分说明；
5. **与官方公布内容冲突**：同一年份、同一卷别存在两个版本且无法判定权威者 → `conflict`，隔离待人工裁决；
6. **来源为 T4 且未交叉验证**。

## 3. 采信流程

```
发现线索 → 查来源等级(T1-T4)
   ├─ T4/无来源 ────────────► data/quarantine/（隔离，标记 rejected 或 pending）
   └─ T1/T2/T3 → 抽取正文 → 记录 source(url, tier, fetched_at, license)
                    → 与第二个独立来源比对
                        ├─ 一致 → verification.status = verified
                        ├─ 只有一个来源 → single_source（可用，但 UI/导出时标注）
                        └─ 冲突 → conflict（隔离，人工裁决）
```

- **独立来源**指不同主体的发布方（例如考试院 + 中国教育在线，或两个不同媒体各自报道）。同一篇稿子的不同转载站**不算**两个来源。
- 交叉验证记录写入 `source.evidence[]`，包含 url、tier、checked_at、note。

## 4. 抓取礼仪（适配器必须遵守）

1. 检查 `robots.txt`，遵守 `Crawl-delay`；单域名并发 ≤ 1，请求间隔 ≥ 1s；
2. 只抓公开发布页，不绕过登录、不破解付费内容、不使用账号池；
3. 标明 User-Agent 与联系方式，遇 403/429 立即退避并记录；
4. 原卷 PDF/图片等大文件**不进仓库**，只登记路径与 sha256（`full_text_policy: index_only`）；
5. 采集结果必须带 `fetched_at`，便于日后复核；源站删除内容时，题目降级为 `single_source` 并在备注中说明。
